Deployment

  1. Push code to GitHub.
  2. Deploy on Render/Railway/Fly.io with Docker or direct `uvicorn` command.
  3. Set start command: uvicorn app:app --host 0.0.0.0 --port $PORT

This is a custom FastAPI system, not Streamlit.
